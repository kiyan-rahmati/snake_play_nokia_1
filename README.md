# 🐍 Snake Play Nokia

### Relive the Classic Nokia Snake Experience

A nostalgic Snake game inspired by classic Nokia mobile phones, rebuilt for modern browsers with pixel-style visuals, retro themes, and an arcade-inspired experience.

🎮 **[Play Online](https://kiyan-rahmati.github.io/snake_play_nokia_1/)**

---

## 📱 About the Project

**Snake Play Nokia** brings back the fun of the classic Snake game with a modern web experience.

The project combines retro Nokia-inspired design with modern web technologies to create a game that is easy to access and enjoyable on different screen sizes.

Whether you remember playing Snake on an old Nokia phone or are discovering it for the first time, this project is made for you.

## ✨ Features

- 🐍 Classic Snake gameplay
- 📟 Nokia-inspired retro design
- 🎨 Multiple themes and visual styles
- 🕹️ Keyboard and mobile-friendly controls
- 🏆 High scores and achievements
- 🎵 Retro-inspired cassette player interface
- 🌍 Different game worlds and environments
- 📱 Responsive layout for different screen sizes
- 🌙 Day and night themes
- 📶 Progressive Web App support
- 📦 Offline support through a service worker

*Some features may depend on the current implementation of the project.*

## 🕹️ How to Play

1. Open the game in your browser.
2. Start a new game.
3. Control the snake using the available controls.
4. Collect food to grow longer and increase your score.
5. Avoid obstacles and your own tail.
6. Try to beat your highest score!

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Layout, themes, animations, and visual effects
- **JavaScript** — Game logic and interactions
- **Web APIs** — Browser-based features and offline support

## 🚀 Run Locally

You can run the project on your computer without installing a framework.

1. Clone the repository:

   ```bash
   git clone https://github.com/kiyan-rahmati/snake_play_nokia_1.git
   ```

2. Open the project folder:

   ```bash
   cd snake_play_nokia_1
   ```

3. Start a local server or open `index.html` in your browser.

   For the best experience, use a local development server, especially when testing offline features and the service worker.

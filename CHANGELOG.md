# Changelog

## 2.0.0
Complete rewrite for reliability.

- Replaced 130+ interdependent scripts with 9 small, ordered files (no build step, works from `file://`).
- New pure game engine with 30 automated tests (`npm test`).
- Five worlds: Nokia Origins, Pixel Rush, Snake Maze, Neon Overdrive, Nokia Legend.
- Canvas renderer with LCD / pixel / stone / neon looks, particles, screen shake, bonus stars.
- Profile, settings, stats, 13 achievements, day/night theme, offline support (PWA).
- Touch controls: swipe on the board and an on-screen D-pad.

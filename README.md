# Nokia Snake

A modern web recreation of the classic button-phone Snake experience.

## Features

- Monochrome LCD-style display
- Nokia-inspired candybar phone UI
- Physical-style keypad controls
- 2 / 4 / 6 / 8 movement
- 5 or OK for pause/start
- Arrow keys and WASD support
- Button press animation
- Pixel-style Snake and food
- Score + persistent high score
- Game Over / Pause screens
- Responsive layout
- No external libraries

## Run

Open `index.html` in a browser.

## Controls

- `2` = Up
- `4` = Left
- `6` = Right
- `8` = Down
- `5` = Pause / Start
- `OK` = Pause / Start
- Arrow keys / WASD = Move
